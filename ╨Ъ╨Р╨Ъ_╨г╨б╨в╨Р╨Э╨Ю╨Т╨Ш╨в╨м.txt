МЯФЛЯ ЧАТ — как превратить в приложение на телефоне и компьютере
===================================================================

В папке «загрузить_на_GitHub» лежат 6 файлов — это и есть приложение.
Их нужно один раз положить на бесплатный сайт GitHub Pages. Делать это нужно с компьютера, займёт минут 10.

ШАГ 1. Аккаунт
  Зайди на github.com → Sign up → зарегистрируйся (почта, пароль, ник).
  Ник будет в адресе приложения, например vika-myaflya.

ШАГ 2. Создать хранилище
  Вверху справа «+» → New repository.
  Repository name: myaflya
  Отметь Public → нажми Create repository.

ШАГ 3. Загрузить файлы
  На открывшейся странице нажми ссылку «uploading an existing file».
  Перетащи туда ВСЕ 6 файлов из папки «загрузить_на_GitHub»
  (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable.png).
  Внизу нажми зелёную кнопку Commit changes.

ШАГ 4. Включить сайт
  Вверху вкладка Settings → слева Pages.
  Source: Deploy from a branch. Branch: main, папка / (root) → Save.
  Подожди 1–2 минуты и обнови страницу — появится адрес вида:
  https://ТВОЙ-НИК.github.io/myaflya/

ШАГ 5. Установить
  Телефон (Android): открой адрес в Chrome, Samsung Internet или Яндекс Браузере →
  меню (⋮) → «Установить приложение» или «Добавить на главный экран».
  Появится значок с котиком «Мяфля».
  Компьютер: открой адрес в Chrome или Яндекс Браузере → в адресной строке значок
  «Установить» (монитор со стрелкой) или меню → «Установить Мяфля чат».

ШАГ 6. Подружке
  Просто отправь ей ссылку. Она установит так же и создаст СВОЙ профиль со своим паролем.
  Её чаты, ключи и память хранятся на её телефоне, твои — на твоём. Друг друга вы не видите.

-------------------------------------------------------------------
ВАЖНО
• В коде на GitHub нет ни ключей, ни памяти, ни чатов — всё это хранится только
  на устройстве, зашифрованное паролем профиля. Поэтому сайт может быть публичным.
• Файл «Тесса_память_Вика.json» НЕ загружай на GitHub — его загружаешь только
  в свой профиль: 🧠 Память → «Загрузить файл памяти».
• Пароль профиля восстановить нельзя. Если забыть — профиль можно только удалить.
• Перенести профиль с компьютера на телефон: ⚙ → 👤 Профиль → «Сохранить профиль в файл»,
  потом на телефоне на экране входа → «загрузить профиль из файла» и войти тем же паролем.
• Старые чаты из «Мяфля_чат.html»: там нажми «💾 Сохранить все чаты в файл»,
  потом в приложении ⚙ → 👤 Профиль → «Загрузить чаты». Ключ нужно будет вписать заново.
• Обновить приложение: загрузи новые файлы в то же хранилище (с заменой) —
  у всех обновится само при следующем открытии.
• Песни и картинки хранятся в браузере на устройстве; если очистить данные браузера
  или удалить приложение — они пропадут. Важное скачивай.

Без сайта тоже можно: открой index.html двойным щелчком на компьютере — всё работает,
только значка на главном экране не будет.
